# Crystal Check — legal pages

Public privacy policy, terms of use and disclaimers for the Crystal Check app, served with GitHub Pages:

- https://edumaf.github.io/crystal-check-legal/privacy.html
- https://edumaf.github.io/crystal-check-legal/terms.html
- https://edumaf.github.io/crystal-check-legal/disclaimers.html

The pages are generated in the app repository (`npx tsx scripts/build-legal-pages.ts` writes `legal/*.html`).
Don't edit them here by hand: change `src/core/legal/documents.ts` there, rebuild, and copy the files over.
